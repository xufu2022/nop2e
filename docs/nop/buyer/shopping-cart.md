# Shopping Cart
role: buyer
url: /cart

- Buyer can add a product to the cart — cart item count increases by 1
- Buyer can add multiple products to the cart — each product appears as a separate cart row
- Buyer can update item quantity in the cart — updated quantity shown in cart row
- Buyer can remove an item from the cart — item no longer appears in cart, count decreases
- Buyer can see the cart subtotal update when quantity changes — subtotal reflects new amount
- Buyer can continue shopping from the cart — redirected back to the store
- Buyer can proceed to checkout from the cart — redirected to checkout page
