# Wish List
role: buyer
url: /wishlist

- Buyer can add a product to the wish list — wish list count increases by 1
- Buyer can view the wish list — all added products shown with names and prices
- Buyer can remove a product from the wish list — product no longer shown in wish list
- Buyer can move a wish list item to the cart — item appears in cart, removed from wish list
- Buyer can add a wish list item directly to the cart — cart count increases by 1
- Buyer can share the wish list via a public link — shared page shows same products
