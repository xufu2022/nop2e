# Checkout
role: buyer
url: /checkout

- Buyer can complete checkout with a saved address — order placed successfully, order confirmation page shown
- Buyer can enter a new shipping address during checkout — address accepted, proceeds to shipping method step
- Buyer can select a shipping method — method selected, proceeds to payment step
- Buyer can select a payment method — method selected, proceeds to order confirmation step
- Buyer can apply a valid coupon code — discount reflected in order total
- Buyer can apply an invalid coupon code — error message shown, total unchanged
- Buyer can review the order summary before placing — all items, shipping, and total visible
- Buyer can place the order — redirected to order confirmation page with order number
