# Message Template Management
role: admin
url: /Admin/MessageTemplate

- Admin can view the message template list — list page loads with all default templates visible
- Admin can search message templates by name — only matching template shown in the grid
- Admin can edit a message template subject — change saved, updated subject visible on detail page
- Admin can edit a message template body — rich text content saved on detail page
- Admin can activate a message template — template marked as active in the list
- Admin can deactivate a message template — template marked as inactive in the list
- Admin can set a BCC email address on a message template — BCC address saved on detail page
