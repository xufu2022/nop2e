# Customer Management
role: admin
url: /Admin/Customer

- Admin can view the customer list — list page loads with heading visible
- Admin can search customers by email — only matching customer shown in the grid
- Admin can search customers by name — only matching customer shown in the grid
- Admin can create a new customer with email and password — saved successfully, redirected to customer list
- Admin can edit a customer email — change saved, updated email visible in customer list
- Admin can assign a customer role — role change saved, visible on customer detail page
- Admin can delete a customer — confirm the dialog, customer removed from list
- Admin can view a customer's order history — orders listed on customer detail page
