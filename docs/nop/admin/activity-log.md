# Activity Log
role: admin
url: /Admin/ActivityLog

- Admin can view the activity log list — list page loads with recent entries visible
- Admin can filter activity log by activity type — only entries of that type shown in the grid
- Admin can filter activity log by customer email — only that customer's activities shown
- Admin can filter activity log by date range — only entries within range shown in the grid
- Admin can view activity log entry details — comment and IP address visible in the grid
- Admin can view activity log types — types list page loads under Configuration
- Admin can enable an activity log type — type marked as enabled in the types list
- Admin can disable an activity log type — type marked as disabled in the types list
