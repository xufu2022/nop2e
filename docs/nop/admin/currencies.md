# Currency Management
role: admin
url: /Admin/Currency

- Admin can view the currency list — list page loads with heading visible
- Admin can edit a currency exchange rate — change saved, updated rate visible in currency list
- Admin can set a currency as the primary store currency — currency marked as primary in the list
- Admin can set a currency as the primary exchange rate currency — setting saved in the list
- Admin can publish a currency — currency marked as published in the list
- Admin can unpublish a currency — currency marked as not published in the list
- Admin can update live exchange rates — rates refreshed and updated values visible in the list
