# Product Review Management
role: admin
url: /Admin/ProductReview

- Admin can view the product review list — list page loads with heading visible
- Admin can search reviews by product name — only reviews for that product shown in the grid
- Admin can search reviews by customer email — only that customer's reviews shown in the grid
- Admin can filter reviews by approval status — grid shows only approved or pending reviews
- Admin can approve a pending review — review status updated to approved in the list
- Admin can reject an approved review — review status updated to not approved in the list
- Admin can edit the review title and text — changes saved, updated content visible on detail page
