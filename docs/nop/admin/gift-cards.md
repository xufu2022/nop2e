# Gift Card Management
role: admin
url: /Admin/GiftCard

- Admin can view the gift card list — list page loads with heading visible
- Admin can search gift cards by coupon code — only matching gift card shown in the grid
- Admin can filter gift cards by activation status — grid shows only active or inactive cards
- Admin can edit a gift card amount — change saved, updated amount visible in gift card detail
- Admin can deactivate a gift card — card marked as inactive in the list
- Admin can view gift card usage history — usage entries listed on the detail page
