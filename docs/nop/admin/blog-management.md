# Blog Management
role: admin
url: /Admin/Blog

- Admin can view the blog post list — list page loads with heading visible
- Admin can create a blog post with title and body — saved successfully, redirected to blog list
- Admin can edit a blog post title — change saved, updated title visible in blog list
- Admin can publish a blog post — post marked as published, visible on the public blog
- Admin can unpublish a blog post — post marked as unpublished, no longer visible on public blog
- Admin can search blog posts by title — only matching posts shown in the grid
- Admin can delete a blog post — confirm the dialog, post removed from list
