# Language Management
role: admin
url: /Admin/Language

- Admin can view the language list — list page loads with heading visible
- Admin can edit a language name — change saved, updated name visible in language list
- Admin can set a language as the default — language marked as default in the list
- Admin can publish a language — language marked as published in the list
- Admin can unpublish a language — language marked as not published in the list
- Admin can set the display order of a language — updated order reflected in the list
- Admin can export language resources to XML — file downloaded with resource strings
