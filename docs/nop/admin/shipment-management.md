# Shipment Management
role: admin
url: /Admin/Shipment

- Admin can view the shipment list — list page loads with heading visible
- Admin can search shipments by tracking number — only matching shipment shown in the grid
- Admin can filter shipments by shipped date range — only shipments within range shown in the grid
- Admin can filter shipments by delivery date range — only shipments within range shown in the grid
- Admin can view shipment details — detail page loads with order reference and items listed
- Admin can mark a shipment as shipped with a tracking number — status updated, tracking number saved
- Admin can mark a shipment as delivered — delivery date recorded, status updated in the list
- Admin can print a packing slip for a shipment — PDF or print view opens
