# Shipping Method Management
role: admin
url: /Admin/Shipping

- Admin can view the shipping provider list — list page loads with installed providers visible
- Admin can configure a fixed-rate shipping provider — rate saved, provider enabled in list
- Admin can view the shipping method list — list page loads under Shipping > Shipping Methods
- Admin can edit a shipping method name — change saved, updated name visible in method list
- Admin can edit a shipping method description — change saved on method detail page
- Admin can set the display order of a shipping method — updated order reflected in the list
- Admin can restrict a shipping method to specific countries — restrictions saved on method detail
