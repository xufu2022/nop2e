# Specification Attribute Management
role: admin
url: /Admin/SpecificationAttribute

- Admin can view the specification attribute list — list page loads with heading visible
- Admin can search specification attributes by name — only matching attribute shown in the grid
- Admin can edit a specification attribute name — change saved, updated name visible in attribute list
- Admin can edit a specification attribute option name — change saved, updated option visible in attribute detail
- Admin can set the display order of a specification attribute — updated order reflected in the list
