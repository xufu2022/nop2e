# Customer Role Management
role: admin
url: /Admin/CustomerRole

- Admin can view the customer role list — list page loads with all default roles visible
- Admin can edit a customer role name — change saved, updated name visible in role list
- Admin can enable tax exemption for a customer role — setting saved on role detail page
- Admin can set a free shipping flag on a customer role — setting saved on role detail page
- Admin can assign a discount to a customer role — discount visible on role detail page
