# Manufacturer Management
role: admin
url: /Admin/Manufacturer

- Admin can view the manufacturer list — list page loads with heading visible
- Admin can create a manufacturer with a name — saved successfully, redirected to manufacturer list
- Admin can search manufacturers by name — only matching manufacturer shown in the grid
- Admin can edit a manufacturer name — change saved, updated name visible in manufacturer list
- Admin can upload a manufacturer logo — image visible on manufacturer detail page
- Admin can delete a manufacturer — confirm the dialog, manufacturer removed from list
