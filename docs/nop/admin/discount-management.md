# Discount Management
role: admin
url: /Admin/Discount

- Admin can view the discount list — list page loads with heading visible
- Admin can create a percentage discount with a coupon code — saved successfully, redirected to discount list
- Admin can create a fixed amount discount — saved successfully, discount visible in list
- Admin can search discounts by name — only matching discount shown in the grid
- Admin can edit a discount percentage — change saved, updated value visible in discount list
- Admin can deactivate a discount — discount marked inactive in the list
- Admin can delete a discount — confirm the dialog, discount removed from list
