# Product Attribute Management
role: admin
url: /Admin/ProductAttribute

- Admin can view the product attribute list — list page loads with heading visible
- Admin can search product attributes by name — only matching attribute shown in the grid
- Admin can edit a product attribute name — change saved, updated name visible in attribute list
- Admin can edit a product attribute description — change saved on attribute detail page
- Admin can edit a predefined value name — change saved, updated value visible in attribute detail
