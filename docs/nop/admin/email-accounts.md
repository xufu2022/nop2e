# Email Account Management
role: admin
url: /Admin/EmailAccount

- Admin can view the email account list — list page loads with heading visible
- Admin can edit an email account display name — change saved, updated name visible in account list
- Admin can edit SMTP host and port settings — changes saved on account detail page
- Admin can mark an email account as default — account marked as default in the list
- Admin can send a test email from an email account — success notification displayed
