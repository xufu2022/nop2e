# Newsletter Subscriber Management
role: admin
url: /Admin/NewsletterSubscription

- Admin can view the newsletter subscriber list — list page loads with heading visible
- Admin can search subscribers by email — only matching subscriber shown in the grid
- Admin can filter subscribers by active status — grid shows only active or inactive subscribers
- Admin can filter subscribers by store — only subscribers from that store shown in the grid
- Admin can export newsletter subscribers to CSV — file downloaded with subscriber data
- Admin can deactivate a newsletter subscription — subscriber marked inactive in the list
