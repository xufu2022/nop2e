# Return Request Management
role: admin
url: /Admin/ReturnRequest

- Admin can view the return request list — list page loads with heading visible
- Admin can search return requests by order number — only matching request shown in the grid
- Admin can filter return requests by status — only requests with that status shown in the grid
- Admin can view return request details — detail page loads with customer, product, and reason visible
- Admin can update the return request status to Received — status change saved, visible in list
- Admin can update the return request status to Refund Issued — status change saved, visible in list
- Admin can add a staff note to a return request — note saved and visible on the detail page
