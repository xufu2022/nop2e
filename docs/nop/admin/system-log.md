# System Log
role: admin
url: /Admin/Log

- Admin can view the system log list — list page loads with recent entries visible
- Admin can filter log by log level — only entries at that level shown in the grid
- Admin can filter log by message keyword — only entries containing keyword shown in the grid
- Admin can filter log by date range — only entries within range shown in the grid
- Admin can view system log entry details — full message and exception visible on detail page
