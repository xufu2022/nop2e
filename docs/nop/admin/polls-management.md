# Poll Management
role: admin
url: /Admin/Poll

- Admin can view the poll list — list page loads with heading visible
- Admin can edit a poll question — change saved, updated question visible in poll list
- Admin can publish a poll — poll marked as published in the list
- Admin can unpublish a poll — poll marked as not published in the list
- Admin can set poll start and end dates — dates saved on poll detail page
- Admin can edit an existing poll answer option — change saved, updated option visible on detail page
- Admin can view poll results with vote counts — answer vote counts visible on detail page
