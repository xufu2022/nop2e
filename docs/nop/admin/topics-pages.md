# Topic (Page) Management
role: admin
url: /Admin/Topic

- Admin can view the topic list — list page loads with heading visible
- Admin can search topics by system name — only matching topic shown in the grid
- Admin can edit a topic title — change saved, updated title visible in topic list
- Admin can edit topic body content — rich text content saved on topic detail page
- Admin can publish a topic — topic marked as published in the list
- Admin can unpublish a topic — topic marked as not published in the list
- Admin can set a topic to require SSL — setting saved on topic detail page
