# Product Management

- Admin can view the product list
- Admin can create a product with name, SKU, and price — saved successfully, redirected to product list
- Admin can search products by name — only matching products shown in the grid
- Admin can edit a product name — change saved, updated name visible in product list
- Admin can delete a product — confirm the dialog, product removed from list
