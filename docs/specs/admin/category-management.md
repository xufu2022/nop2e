# Category Management
role: admin
url: /Admin/Category

- Admin can view the category list — list page loads with heading visible
- Admin can create a category with a name — saved successfully, redirected to category list
- Admin can search categories by name — only matching categories shown in the grid
- Admin can edit a category name — change saved, updated name visible in category list
- Admin can delete a category — confirm the dialog, category removed from list
