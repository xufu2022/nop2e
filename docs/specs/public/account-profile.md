# Account Profile
role: buyer
url: /customer/info

- Buyer can view their account information — first name, last name, and email displayed
- Buyer can update their first name and last name — changes saved, success notification shown
- Buyer can update their email address to a new valid email — updated email shown on save
- Buyer cannot update email to one already registered by another account — error message shown
- Buyer cannot clear the first name field and save — validation error shown
- Buyer can change their password by providing the current and a new password — password updated successfully
- Buyer cannot change password with an incorrect current password — error message shown
- Buyer cannot set a new password shorter than the minimum length — validation error shown
