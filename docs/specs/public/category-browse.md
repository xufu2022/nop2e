# Category Browse
role: public
url: /electronics

- Guest can view products listed in a category — product cards shown with names and prices
- Guest can sort products by price ascending — lowest-priced product appears first
- Guest can sort products by price descending — highest-priced product appears first
- Guest can sort products by name — products shown in alphabetical order
- Guest can change the number of products displayed per page — product count matches selection
- Guest can navigate to a product detail page from the category listing — product detail page loads
- Guest can see subcategory links on a parent category page — subcategory tiles or links visible
- Guest navigating to an empty category sees an appropriate message — no products message shown
