# Newsletter Subscription
role: public
url: /

- Guest can subscribe to the newsletter with a valid email via the footer form — success confirmation shown
- Guest cannot subscribe with an empty email field — validation error shown
- Guest cannot subscribe with an invalid email format — validation error shown
- Submitting an already-subscribed email shows an already-subscribed message — no duplicate subscription created
- Registered user can subscribe to the newsletter from the account preferences page — subscription status updated
