# Product Reviews
role: public
url: /product

- Guest can view existing reviews on a product page — reviews listed with rating and text
- Guest can see the average star rating on a product page — rating visible near product title
- Guest cannot submit a review without logging in — redirected to login page when clicking "write a review"
- Registered user can submit a review with a title, text, and star rating — review submitted message shown
- Registered user cannot submit a review with missing title — validation error shown on title field
- Registered user cannot submit a review with missing rating — validation error shown on rating field
- Registered user can see their submitted review after approval — review visible on the product page
