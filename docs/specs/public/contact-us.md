# Contact Us
role: public
url: /contactus

- Guest can view the contact form — form fields and submit button visible
- Guest can submit the contact form with all required fields filled — success message shown
- Guest cannot submit the form without a name — validation error shown on name field
- Guest cannot submit the form without an email — validation error shown on email field
- Guest cannot submit the form without a message body — validation error shown on message field
- Guest cannot submit the form with an invalid email format — validation error shown
- Registered user sees name and email pre-filled on the contact form — fields populated from account
