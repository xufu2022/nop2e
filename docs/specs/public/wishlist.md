# Wishlist
role: buyer
url: /wishlist

- Buyer can view an empty wishlist — empty state message shown
- Buyer can add a product to the wishlist from a product detail page — wishlist count increases
- Buyer can add a product to the wishlist from a category listing — wishlist count increases
- Buyer adding the same product to the wishlist twice does not create a duplicate — only one entry shown
- Buyer can view all wishlisted products with their names and prices — product info displayed
- Buyer can remove an individual item from the wishlist — item no longer shown in the list
- Buyer can add a wishlist item to the cart — item appears in cart, wishlist count decreases
- Guest attempting to add a product to the wishlist is prompted to log in — login page or prompt shown
