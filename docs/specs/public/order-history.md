# Order History
role: buyer
url: /order/history

- Buyer can view their list of past orders — order numbers, dates, and totals shown
- Buyer can open an order to view its detail — order items, quantities, and prices shown
- Buyer can see the order status on the detail page — status label visible
- Buyer can see the shipping address on the order detail page — address displayed
- Buyer with no orders sees an empty state — no orders message shown
- Buyer can reorder items from a past order — previous order items added to cart
- Buyer can print an order from the detail page — print dialog triggered
