# Product Search
role: public
url: /search

- Guest can search products by keyword — matching products shown in search results
- Guest can search with a keyword that matches no products — "no products found" message shown
- Guest can filter search results by category — only products from that category shown
- Guest can filter search results by price range — only products within range shown
- Guest can sort search results by price ascending — cheapest product appears first
- Guest can sort search results by price descending — most expensive product appears first
- Guest can sort search results by name — products shown in alphabetical order
- Guest can navigate to a product from search results — product detail page loads
