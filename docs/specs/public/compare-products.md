# Compare Products
role: public
url: /compareproducts

- Guest can add a product to the compare list from a category page — compare list indicator updated
- Guest can add multiple products to the compare list — all products appear as columns in the comparison table
- Guest can view product attributes side by side in the comparison table — attribute rows shown for each product
- Guest can navigate to a product detail page from the comparison table — product detail page loads
- Guest can remove a product from the comparison table — product column disappears from the table
- Guest can clear the entire comparison list — empty state shown on the compare page
- Guest adding more than the maximum allowed products sees an appropriate message — limit warning shown
