# Agent Modes for playwrighte2e

## /update-tests [keyword]

Update spec files and regenerate only affected POMs/test specs after tests pass.

### Workflow

User runs: `/update-tests order-management`

1. Find spec file by keyword match ONLY: `docs/specs/**/[keyword].md`
2. Read frontmatter (required):
   ```yaml
   feature: order-management
   pages: [AdminOrderListPage, AdminOrderDetailsPage]
   description: Admins can view, filter, and see order details
   routes: [/Admin/Order/List, /Admin/Order/Details]
   ```
3. Regenerate ONLY:
   - POMs listed in `pages` array
   - Corresponding `.spec.ts` file
4. Report results and stop

### Constraints (Do NOT)

- Do not scan other spec files
- Do not explore unrelated pages
- Do not generate files not in `pages` list
- Do not ask for clarification
- Do not run tests
- Do not infer scope beyond what's in frontmatter

### Requirements

Every spec file MUST have frontmatter with `feature`, `pages`, `description`, and `routes`.

If frontmatter is missing → refuse and ask user to add it first.

### Example

```
/update-tests order-management
```

Agent finds `docs/specs/admin/order-management.md`, reads `pages: [AdminOrderListPage, AdminOrderDetailsPage]`, regenerates those 2 POMs + the spec file.
