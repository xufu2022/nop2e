# Claude Code Instructions for playwrighte2e

## File Generation — Explicit Request Only

**Do NOT use `/generate-tests` or any other file generation skill unless explicitly asked.**

- Only generate files when the user specifically requests it with clear scope (e.g., "create test specs for login", "generate POMs for the shopping cart")
- Do not auto-scan `docs/specs/` or assume what needs to be regenerated
- Do not explore multiple pages or features unless specifically requested
- When asked for help with code, provide explanations or fixes — do not generate new files

## Clarify First

If the request is ambiguous (e.g., "fix the menu tests"), ask what the user needs:
- New test specs?
- Updates to existing page objects?
- Test fixes?

Then act only on the explicit answer.

## Keep It Focused

- Minimize tool calls and exploration
- Answer quickly for simple questions
- Only use comprehensive tools (like `/generate-tests`) when explicitly requested with full scope
